# Pure Dairy Ecommerce Website

A full-stack MERN-style dairy ecommerce platform with customer + admin portal.

---

# FEATURES

## Customer Side

- User Registration/Login
- Forgot Password
- Profile Dashboard
- Shop Products
- Product Search
- Add To Cart
- Checkout
- Order History
- Responsive Design

---

## Admin Side

- Admin Login
- Dashboard Analytics
- Product Management
- Orders Management
- User Management

---

# TECH STACK

## Frontend

- HTML5
- CSS3
- JavaScript
- LocalStorage (initial)
- Responsive Design

---

## Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt
- Nodemailer
